# Glossary for Vietnamese Business and Market Intelligence Writing

Use this glossary to keep terminology natural and consistent. It is a writing reference, not a replacement for definitions, schemas, or status values in source artifacts.

## Application rules

- Preserve official company, product, program, platform, and standard names.
- Preserve exact schema fields and decision labels when they appear as data.
- Use the preferred wording when it fits the source meaning; do not force a term into every context.
- Introduce an acronym only when it will recur or when the audience is expected to know it.
- Keep an established English term when a Vietnamese translation would sound forced or lose precision. Explain it briefly at first use when needed.

## Preferred terminology

| Term or idea | Preferred Vietnamese wording | Avoid or use cautiously | Notes |
|---|---|---|---|
| Market Intelligence | Market Intelligence | trí tuệ thị trường | Use “phân tích thị trường” only when that is the actual activity, not as a replacement for the process name. |
| Smart City | Smart City; đô thị thông minh | thành phố thông minh when it changes an official label | Follow the source or official program name. |
| Signal | tín hiệu; Signal for a pipeline stage or ID | dấu hiệu thị trường in every context | “Tín hiệu thị trường” is natural in narrative prose. Preserve stage names and IDs. |
| Opportunity / Threat | cơ hội / thách thức; Opportunity / Threat for the stage name | mối đe dọa when the meaning is broader competitive pressure | Preserve exact pipeline labels and IDs. |
| Product Mapping | Product Mapping; xác định nhóm giải pháp phù hợp | ánh xạ sản phẩm | Do not imply direct mapping to the VSF catalog when the stage is neutral. |
| Product Gap | Product Gap; khoảng trống năng lực sản phẩm | lỗ hổng sản phẩm | Use “khoảng trống năng lực” when comparing required and available capabilities. |
| Action | hành động đề xuất; Action for a pipeline record | hành động hóa | Distinguish a proposal from a final action. |
| Human-in-the-loop (HITL) | bước rà soát/phê duyệt của con người; HITL | con người trong vòng lặp | Retain `HITL` in process or gate names. |
| Digital Twin | Digital Twin; mô hình số phản ánh trạng thái của tài sản/hệ thống | bản sao kỹ thuật số without explanation | Use the official or audience-familiar form. |
| Internet of Things (IoT) | IoT; thiết bị kết nối | vạn vật kết nối in business copy | Keep `IoT` when it is a recognized solution category. |
| Artificial Intelligence (AI) | AI; trí tuệ nhân tạo | công nghệ AI technology | Avoid redundant bilingual mixing. |
| interoperability | khả năng liên thông; khả năng các hệ thống trao đổi và sử dụng dữ liệu | tính tương tác giữa các hệ thống | Explain what must interoperate if the distinction matters. |
| integration | tích hợp; kết nối when the meaning is only connectivity | hội nhập hệ thống | Do not use “tích hợp” if the source only supports data exchange. |
| platform | nền tảng | platform | Keep English only in official names or established compound terms. |
| ecosystem | hệ sinh thái | hệ sinh thái hóa | Name the actors or services when “hệ sinh thái” is too vague. |
| use case | use case; tình huống ứng dụng | ca sử dụng | Prefer Vietnamese for general business readers; preserve `use case` in technical taxonomies. |
| end-to-end | xuyên suốt; từ đầu đến cuối | end-to-end when unnecessary | Describe actual journey or process boundaries when possible. |
| real-time | thời gian thực | real time; realtime | Use only when technically supported; otherwise use “gần thời gian thực” or stated latency. |
| data-driven | dựa trên dữ liệu | dẫn dắt bởi dữ liệu | State which decision the data supports when possible. |
| insight | nhận định; phát hiện có ý nghĩa; thông tin hỗ trợ quyết định | insight in generic prose | Do not turn every observation into an “insight”. |
| capability | năng lực; khả năng | tính năng when broader than a feature | Distinguish product capability from an individual feature. |
| feature | tính năng; chức năng | năng lực when referring to one discrete product function | Use “năng lực” when the scope also includes process, data, people, governance, or several features. |
| service blueprint | sơ đồ mô tả hành trình và cách thức phục vụ khách hàng; service blueprint in a specialist taxonomy | sơ đồ dịch vụ without explanation | Preserve the English term when it is an official deliverable name; otherwise explain what the diagram shows. |
| pilot | thử nghiệm; thử nghiệm giới hạn | pilot in general business prose | Preserve `PILOT` when it is an enum or schema value. |
| go/no-go | quyết định tiếp tục hay dừng; tiêu chí tiếp tục/dừng | đi/không đi | Preserve the source value when `go/no-go` is an official gate or field. |
| false positive | cảnh báo sai; tỷ lệ cảnh báo sai | dương tính giả in non-clinical business copy | Use “tỷ lệ” only when the source defines a rate. |
| Smart Stadium | Sân vận động thông minh; Smart Stadium when official | dịch tên sản phẩm chính thức without confirmation | Follow the official product or program name used by the source. |
| priority | mức độ ưu tiên; priority when a schema field | độ ưu tiên | Preserve `HIGH`, `MEDIUM`, `LOW`, and `CRITICAL` exactly. |
| operations | vận hành; hoạt động vận hành | operation | Name the operating domain when known. |
| operator | đơn vị vận hành; nhân sự vận hành | nhà vận hành when ambiguous | Select the subject that matches the source. |
| governance | cơ chế quản trị; quản trị | quản trị hóa | Specify data, AI, platform, or program governance. |
| stakeholder | bên liên quan | stakeholder | Name the stakeholder group when known. |
| customer journey | hành trình khách hàng; hành trình người dùng | customer journey in general prose | Match the audience: visitor, resident, passenger, or operator. |
| seamless experience | trải nghiệm liền mạch | trải nghiệm không đường may | Explain which handoff or interruption is removed. |
| optimize | tối ưu; cải thiện | tối ưu hóa in every sentence | Prefer measurable verbs when supported: giảm thời gian, tăng độ chính xác. |
| enhance efficiency | rút ngắn thời gian; giảm thao tác; sử dụng nguồn lực hiệu quả hơn | nâng cao hiệu quả without an object | State the concrete operational effect. |
| scalable | có thể mở rộng | có tính mở rộng | State what can expand: users, sites, devices, data, or services. |
| resilience | khả năng duy trì và phục hồi hoạt động | tính chống chịu in generic business copy | “Khả năng chống chịu” remains suitable in established policy or climate contexts. |
| sustainability | phát triển bền vững; tính bền vững | sustainability | Specify energy, emissions, resources, or long-term operation when supported. |
| implication | hàm ý; tác động đối với; điều này cho thấy | hệ quả tất yếu | Match the certainty of the evidence. |
| recommendation | khuyến nghị; đề xuất | lời khuyên | Distinguish a recommendation from an approved action. |

## Candidate update rule

When the user repeatedly corrects a term or phrase, record it as a candidate glossary update in the response. Do not modify this file unless the user explicitly asks. When approved, add the term with its preferred form, discouraged form, scope, and one short example.
